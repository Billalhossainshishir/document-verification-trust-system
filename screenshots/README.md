# Screenshot capture checklist

Use **real captures from the running project**. Do not use generated mockups as technical evidence.

Recommended recruiter screenshots:

1. Sample document registration with generated Verification ID and SHA-256 fingerprint.
2. Same-file verification showing VERIFIED.
3. Modified-file verification showing FAILED.
4. Audit trail and verification receipt / QR metadata.

Use only sample/demo documents that contain no private information.
